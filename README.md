An AI-powered healthcare triage and referral platform designed to improve access to primary healthcare, particularly in rural areas.

- Uses XGBoost for patient severity classification.
- Supports Web Kiosk, WhatsApp/SMS, and USSD-based access concepts.
- Includes doctor dashboards and referral assistance.
- Built using HTML, CSS, JavaScript, Python, and Leaflet.
